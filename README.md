# 🌱 EcoSid

## Sistema Digital de Monitoramento para a Otimização da Coleta de Lixo Reciclável na Cidade de Sidrolândia

O **EcoSid** é uma plataforma web desenvolvida com o objetivo de facilitar o acesso da população às informações relacionadas à coleta seletiva em Sidrolândia-MS.

A plataforma reúne informações sobre os dias de coleta, localização dos ecopontos e orientações de educação ambiental em um único ambiente digital.

---

## 🎯 Objetivo

Facilitar o acesso da população às informações sobre a coleta seletiva, contribuindo para uma maior organização do descarte de materiais recicláveis e para a conscientização ambiental.

---

## 💡 Funcionalidades

- 🏠 Página inicial com apresentação do projeto;
- 📍 Consulta dos ecopontos;
- 🗺️ Mapa com localização dos ecopontos;
- 📅 Calendário de coleta por bairro;
- 🔎 Pesquisa de bairros sem necessidade de utilizar acentos;
- 🌱 Conteúdo de educação ambiental;
- ℹ️ Informações sobre o projeto;
- 📱 Interface responsiva para computadores e dispositivos móveis.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Leaflet
- OpenStreetMap
- Google Fonts
